# SCS Color Converter

A simple web-based color converter for **SCS Software** games.

Convert between standard **HEX/RGB colors** and the SCS color format directly in your browser.

## Features

- HEX → RGB → SCS
- SCS → RGB → HEX
- Live color preview
- Copy conversion results
- No backend required
- Works entirely in the browser
